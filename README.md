# software-dev-ai-workflow

软件开发 AI 工作流常用 Skill 合集。

## Skill 列表

### 创作与文档

| Skill | 说明 |
| --- | --- |
| author-readme-generator | 根据项目代码自动生成高质量 README 文档 |
| author-build-project-docs | 为项目构建分层式 LLM 友好文档体系(项目扫描、CLAUDE.md 索引、模块文档、变更日志) |
| author-skill | Skill 编写专家,用于创建、编辑和验证 Claude Code Skill |
| manage-claude-session | Claude Code 历史会话查询、分析、提取与总结 |

### 工具

| Skill | 说明 |
| --- | --- |
| tool-api-export | 从后端接口代码生成 OpenAPI / Apifox / Postman / Markdown 等格式的 API 文档 |
| tool-ssh-skill | SSH / 服务器操作(持久连接、连接池、跳板机、SFTP、隧道等) |
| tool-web-fetch | 本地搜索引擎与网页内容获取,绕过 WebSearch / WebFetch 域名限制 |

### 办公文档处理

| Skill | 说明 |
| --- | --- |
| docx | Word 文档创建、读取与编辑 |
| pdf | PDF 读取、合并、拆分、表单填写、OCR 等 |
| pptx | PPT 演示文稿创建与编辑 |
| xlsx | Excel / CSV 表格处理 |
